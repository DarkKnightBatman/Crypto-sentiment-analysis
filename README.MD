# Crypto Sentiment Analytics Dashboard

## Overview
This project analyzes cryptocurrency trader behavior using:
- Bitcoin Fear & Greed Index
- Hyperliquid historical trading data
- Machine Learning models

The dashboard provides insights into:
- Profitability during different market sentiments
- Win rate analysis
- Trader clustering
- Feature importance
- ROC curve evaluation

---

## Technologies Used

- Python
- Streamlit
- Pandas
- Seaborn
- Matplotlib
- Scikit-Learn

---

## Machine Learning Models

- Random Forest Classifier
- Logistic Regression
- K-Means Clustering

---

## Features

- Interactive Streamlit dashboard
- Market sentiment analysis
- PnL visualization
- Win rate tracking
- Feature importance analysis
- Trader segmentation using clustering
- ROC curve comparison

---

## Dataset

Datasets used:
1. Bitcoin Fear & Greed Index
2. Hyperliquid historical trader data
